# Autumn Comic（秋日漫画）

1. 确认当前对话中有用户提供的目标图片。若没有图片，先请用户上传一张图片；不要生成替代图片，也不要仅凭文字描述开始转换。如有多张且目标不明确，询问要转换哪张。
2. 使用可用的 ChatGPT 图像编辑/生成能力，把上传的目标图片作为编辑参考输入。若图片位于本地路径，可先查看以了解画面；否则使用工具支持的最近对话图片引用方式。不要改用纯文字从零生成。图像编辑能力不可用时，说明无法完成转换并请用户稍后重试。
3. 将以下要求写入编辑指令，并根据原图的场景、人物和用户额外要求作少量具体化：

   > 将这张参考图片真正重新绘制为高质量二维漫画插画，而不是仅添加黄色滤镜。尽最大可能保留原图主体、人物身份特征、人物数量、五官、发型、服装、姿势、主体位置、视角、画幅与整体构图。以金黄、橙色、红棕色呈现秋季色彩；加入柔和的秋日下午阳光、轻微逆光、自然柔和的阴影、精致的手绘漫画线条与温暖安静、治愈的氛围。可在原场景适合的位置自然点缀秋叶或落叶，不能遮挡关键主体或破坏主要构图。不要添加文字、Logo、边框或水印。

4. 输出生成的图片。若工具返回的图明显改变人物数量、身份、服装或主要构图，且可再次编辑，则用原图作为主要参考再尝试一次，并明确加强相关保留要求。图像模型不能保证像素级一致，不宣称完全还原。
